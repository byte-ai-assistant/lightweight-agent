# Hello Skill

This is an example skill that demonstrates how to greet someone with a friendly message.

## Purpose
Demonstrates the skill system structure and provides a simple greeting capability.

## Usage

This skill can be used to generate friendly greetings. It's primarily educational to show how skills work.

## Example

When invoked, you can use this skill to create personalized greetings like:
- "Hello, [name]! Welcome to Lightweight Agent!"
- "Greetings, [name]! How can I assist you today?"

## Requirements
None — this is a basic example skill with no external dependencies.
